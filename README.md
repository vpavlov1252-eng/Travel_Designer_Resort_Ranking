# Рейтинг горнолыжных курортов для Travel Designer

## Описание проекта
Проект представляет собой воспроизводимый аналитический пайплайн для оценки потенциала 32 горнолыжных курортов России. 
Включает в себя сбор данных, расчет базового и экспертного рейтинга, анализ факторов, демонстрацию SQL-запросов и интерактивный дашборд.

## Ссылки
* **Интерактивный дашборд в Yandex DataLens:** Собран в DataLens. Скриншоты всех экранов приложены в папке Скриншоты.

## Структура проекта
- `data/raw/` — исходные файлы, предоставленные наставником (JSON, CSV).
- `data/prepared/` — подготовленные витрины данных (`resort_features.csv`, `resort_scores.csv`, `resort_scores_v2.csv`).
- `src/` — исходный код:
  - `prepare_data.py` — сборка и очистка данных (JOIN).
  - `scoring.py` — расчет базовой математической модели (v1).
  - `scoring_v2.py` — расчет экспертной модели (v2) с градусными вилками комфорта (идеал от -2 до -8°C).
  - `scenarios.py` — расчет сценариев с изменением весов.
  - `sql_demo.py` — демонстрация SQL-запросов (JOIN, GROUP BY) к локальной базе.
  - `run_all.py` — запуск базового пайплайна одной командой.
- `notebooks/` — Jupyter-ноутбуки с исследовательским анализом (EDA) и сравнением v1/v2.
- `requirements.txt` — зависимости проекта.

## Инструкция по запуску
1. Установите зависимости: 
   pip install -r requirements.txt
2. Запустите пайплайн (расчет v1 и v2):
   cd src
   python run_all.py
   python scoring_v2.py
   python scenarios.py
   python sql_demo.py

## Методология и допущения
1. **Две модели рейтинга:** Базовая (математическая min-max) и Экспертная (v2). В экспертной модели температура оценивается по шкале комфорта клиента, а снегопад — по категориям. Это лучше отражает потребности реальных горнолыжников.
2. **Региональный турпоток:** Данные Росстата относятся ко всему субъекту РФ, поэтому все курорты одного региона получают одинаковый балл спроса.
3. **OSM:** Количество объектов в радиусе 6 км используется как прокси инфраструктуры. Для соседних курортов (Роза Хутор, Красная Поляна, Газпром) радиусы пересекаются, что может завышать их баллы.
4. **Цены:** При отсутствии цены ски-пасса присваивается нейтральный балл 50.
5. **Координаты:** Для части курортов использованы координаты ближайших населенных пунктов (nearby_feature_proxy).
